# Profession OER Research Sources

This research note records external sources consulted for the all-profession resource expansion. It is not a claim that every listed title is used in every Nigerian programme; programme-specific relevance must be mapped against official curricula before integration.

## Integration policy

Commercial titles from the supplied MBBS CSV are retained only as research references unless an authorized free edition is independently verified. A catalog record qualifies as a free book/resource only when its original source provides a public access path and the record includes evidence such as an open license, public-domain statement, official government/institutional publication, or publisher-authorized free access. Every integrated record should include profession, subject, progression stage, region priority, source type, canonical URL, access/license evidence, verification date, and exact-cover candidates where available.
